# Security

## Reporting a vulnerability

Please report security issues privately using GitHub's **Report a vulnerability** option on the [Security tab](../../security/advisories/new), rather than opening a public issue.

## Handling data

- Never attach packet captures, customer names, hostnames, or IP addresses to issues or pull requests.
- The analyzer reads captures locally. With Copilot enabled, only the Section 11 findings text and the switches used are sent to Copilot. Use `-Copilot Off` to keep a run fully local.
